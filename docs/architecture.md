# Architektura projektu

Projekt se skládá z následujících částí:

- **Frontend:** webová aplikace umožňující autorům nahrát článek a sledovat jeho stav.
- **Backend:** serverová aplikace zpracovávající požadavky, ukládající metadata a zajišťující komunikaci s databází.
- **Databáze:** ukládá články, metadata a informace o uživatelích.
- **Admin rozhraní:** umožňuje správu uživatelů, článků a sledování aktivit.
