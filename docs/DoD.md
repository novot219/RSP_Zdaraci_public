# Definition of Done (DoD)

Položka je „hotová“, pokud:
- Funkčnost je implementovaná a pokrytá testy (alespoň základní).
- Splňuje všechna akceptační kritéria.
- Kód prošel code review a je na větvi `main`.
- Dokumentace (README nebo /docs) je aktualizovaná.
- Nasazení/demonstrace proběhla (pokud dává smysl) a Product Owner viděl výsledek.
- Backlog je aktualizovaný (stav, odvedené SP/hodiny, případné follow-up).
