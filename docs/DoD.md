# Definition of Done (DoD)

Sprint 1 – Základní funkce a login systém



 Struktura projektu je vytvořena a obsahuje soubory pro všechny role (autor.html, redaktor.html, recenzent.html, sefredaktor.html, ctenar.html, admin.html).

 Přihlašovací formulář umožňuje přihlášení pomocí pevně definovaných účtů.

 Po přihlášení je uživatel automaticky přesměrován na stránku své role.

 Login systém obsahuje základní validaci a chybová hlášení při špatných údajích.

 CSS styly a základní UI jsou aplikovány na všechny stránky.



Sprint 2 – Recenze a workflow



 Redaktor má rozhraní pro přiřazení recenzentů ke konkrétním článkům.

 Recenzenti mají přístup k článkům a mohou vložit své posudky.

 Workflow mezi autorem → redaktorem → recenzentem funguje a zachovává stav článku.

 Systém umožňuje sledovat stav článku během recenzního procesu.

 Data článků a recenzí se ukládají a zobrazují správně.



Sprint 3 – Rozhodnutí šéfredaktora



 Šéfredaktor má rozhraní pro schválení, zamítnutí nebo vrácení článku k úpravě.

 Autor vidí aktuální stav článku a může reagovat na rozhodnutí šéfredaktora.

 Stav článku se automaticky aktualizuje podle rozhodnutí.

 Systém uchovává historii verzí a změn.

 O rozhodnutí je uživatel informován vizuálně nebo notifikací.



Sprint 4 – Publikace a čtenář



 Schválené články jsou automaticky publikovány do veřejné části aplikace.

 Čtenář vidí seznam publikovaných článků a může si zobrazit jejich detail.

 Je implementována funkce vyhledávání a filtrování článků.

 Stránka pro čtenáře je responzivní a přehledná.

 Publikované články obsahují veškeré potřebné informace (autor, datum, text atd.).



Sprint 5 – Admin a dokončení



 Administrátor má rozhraní pro správu uživatelských účtů a rolí.

 Je možné přidávat, mazat a upravovat uživatelské účty.

 Dokumentace projektu je doplněna a aktuální.

 Všechny funkce aplikace prošly testováním a fungují dle požadavků.

 Projekt je připraven k finálnímu odevzdání a nasazení.
