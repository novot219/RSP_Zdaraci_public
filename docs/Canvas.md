# Lean/Business Model Canvas – „Žďáráci – Recenzní systém“

Problém: Chaotická e-mailová komunikace, nejasné termíny, necentralizované dokumenty.
Řešení: Webová aplikace pro sběr článků, recenze, editaci a publikaci.
Hodnota (Value): Přehledný a auditovatelný recenzní proces, méně chyb, rychlejší komunikace.
Zákazníci/uživatelé: Autoři, recenzenti, redaktor, šéfredaktor, čtenáři, administrátor.
Kanály: Veřejná webová aplikace (bez instalace).
Klíčové aktivity: Nahrávání článků, přiřazení recenzentů, recenzní formuláře, notifikace, publikace.
Klíčové zdroje: Tým, GitHub, ScrumDesk, MS Teams.
Partneři: (Škola/garant kurzu), případně vzorové aplikace z minulých let.
Náklady: Čas vývoje, údržba repozitáře, hostování (pokud bude).
Metriky: Počet článků ve fázi, SLA recenzí, počet publikovaných čísel, spokojenost uživatelů.
