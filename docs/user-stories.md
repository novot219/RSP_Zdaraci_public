# User Stories

1. Jako autor chci nahrát PDF článku, abych ho mohl odeslat do redakce.
2. Jako autor chci vidět stav svého článku, abych věděl, v jaké fázi se nachází.
3. Jako redaktor chci článek recenzovat, abych mohl schválit jeho publikaci.
4. Jako šéfredaktor chci potvrdit finální rozhodnutí, abych mohl publikovat článek.
5. Jako čtenář chci číst publikované články.
6. Jako administrátor chci spravovat uživatele a sledovat jejich aktivitu.
